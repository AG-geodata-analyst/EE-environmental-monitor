About

Automated Airflow pipeline fetching a 7-day forecast from Open-Meteo, validating with Pydantic, loading into PostgreSQL, running data-quality checks, and publishing via GitHub Pages.

Stack: Airflow 3.1 · Python · Pydantic · PostgreSQL · GitHub Actions · GitHub Pages · Leaflet · Chart.js

Data source: Open-Meteo Forecast API · Built with Apache Airflow
